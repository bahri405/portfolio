Sistem Pemesanan Makanan - KlikPangku.

Status : Project Kuliah

Sebuah sistem pemesanan makanan yang dirancang untuk mempermudah pelanggan dalam memesan makanan secara online. Proyek ini juga dilengkapi dengan integrasi pembayaran digital menggunakan Midtrans untuk mendukung pengalaman transaksi yang lebih modern dan aman.


Fitur Utama

Menu Dinamis: Menampilkan daftar makanan dan minuman yang tersedia dengan deskripsi dan harga.


Keranjang Pemesanan: Pelanggan dapat memilih menu dan menambahkan ke keranjang untuk dipesan.


Integrasi Midtrans: Mendukung berbagai metode pembayaran, seperti kartu kredit, transfer bank, dan e-wallet, melalui Midtrans Payment Gateway.


Notifikasi Real-Time: Admin menerima pemberitahuan pesanan baru untuk mempercepat proses persiapan makanan.


Manajemen Admin: Admin dapat mengelola menu, harga, dan memantau pesanan pelanggan secara efisien.


Teknologi yang Digunakan: HTML, CSS, JavaScript , CSS Bootstrap , Laravel , Midtrans API , Socket.io , Redis , MySQL

Sistem Informasi Persediaan Alat Kerja.

URL : a2pi.my.id

Saya mengembangkan sistem informasi persediaan alat kerja untuk membantu mengelola inventaris secara efektif. Sistem ini dirancang untuk mencatat, memantau, dan mengelola stok alat kerja dengan fitur yang mempermudah administrasi dan laporan persediaan.


Fitur Utama

Manajemen Stok: Melacak persediaan alat kerja, termasuk jumlah masuk dan keluar.


Fitur : Peminjaman dan Pengembalian barang


Cetak Laporan: Menyediakan laporan stok dalam format yang dapat diunduh (PDF/Excel).


Notifikasi: Peringatan untuk stok yang rendah atau alat kerja yang membutuhkan pemesanan ulang.


Teknologi yang Digunakan: HTML, CSS, JavaScript , CSS Bootstrap , Laravel , MySQL
